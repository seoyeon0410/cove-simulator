# COVE 모션 작업 안내서

COVE 의 움직임(모션)을 만드는 분을 위한 안내서입니다. 코딩이나 공학 지식은 필요 없습니다.
**Claude 에게 말로 설명하면 Claude 가 로봇에 맞게 바꿔서 넣어 줍니다.** 이 폴더를 Claude 에서 열면 Claude 가 함께 들어 있는 `CLAUDE.md` 를 읽고 방법을 알게 됩니다.

---

## 1. COVE 는 어떤 로봇인가요

사람이 팔이나 손을 내밀면, 강아지가 장난으로 살짝 무는 것처럼 **부드럽게 물어서 안정감을 주는** 로봇입니다.
몸통, 목, 고개가 움직이고, 눈은 작은 LED 화면 두 개로 표정을 냅니다.

## 2. COVE 의 몸 — 움직이는 곳 4군데 + 눈

| 번호 | 부위 | 어떻게 움직이나 | 얼마나 |
|---|---|---|---|
| 1 | **몸통 돌리기** | 바닥에서 몸 전체가 왼쪽·오른쪽으로 돎 | 정면에서 좌우로 각각 반 바퀴(180°)까지 |
| 2 | **목 들기** | 머리 전체를 위로 들어 올림 | 내려앉은 자세 → 가장 높이 든 자세 |
| 3 | **고개 들기 / 내리기** | 고개를 들었다 내림. **물 때 이 고개를 내려서 팔을 누릅니다** | 내린 자세 → 가장 높이 든 자세 |
| 4 | **고개 좌우 돌리기** | 고개를 왼쪽·오른쪽으로 갸웃 | 조금만 (고개를 중간쯤 들었을 때만 움직이고, 맨 아래·맨 위에서는 안 움직여요) |
| 눈 | **눈 표정** | 눈동자 두 개 (위쪽 4줄만 사용) | 평소(천천히 두리번) / 깜빡 / 왼쪽 보기 / 오른쪽 보기 / 끄기 |

- 각 부위가 갈 수 있는 끝은 미리 재서 막아 두었습니다. **"끝까지"라고 해도 부서지지 않아요.** 범위를 넘으면 그 끝에서 멈춥니다.
- 물기에 쓰는 고개(3번)와 목(2번)은 **힘의 세기도 제한**되어 있어서 팔이 끼어도 세게 누르지 않습니다.

## 3. 지금 들어 있는 기본 동작 3가지

| 이름 | 하는 일 | 걸리는 시간 |
|---|---|---|
| **home** | 모든 부위를 처음 자세(정면, 머리 내림)로 돌아오기 | 3초 |
| **wake** (잠 깨기) | 눈 깜빡 → 몸통 정면 → 목·고개 살짝 들기 → 고개를 좌우로 두 번 두리번 (눈도 따라 봄) | 약 11초 |
| **bite** (물기) | 목·고개를 끝까지 들기 → **3초 기다림 (이때 팔을 넣어요)** → 고개를 약한 힘으로 내려 팔을 물기 → 2초 유지 → 고개를 들어 놓아주고 목을 반쯤 내림 → **5초 기다림 (팔 빼는 시간)** → 처음 자세 | 약 20초 |

이 동작들을 고쳐도 되고, 새로 만들어도 됩니다.

## 4. 처음 한 번만: 준비

1. **노트북에 Claude Code 설치** (이미 있으면 넘어가세요)
2. **로봇 와이파이에 연결**: 이름 `HIDELAB_ROBOWORLD` — 비밀번호는 담당자에게 받으세요.
   (이 와이파이는 인터넷이 안 될 수 있어요. Claude 를 쓰려면 노트북에 인터넷도 필요하니, 휴대폰 테더링 등을 함께 쓰는 방법은 담당자와 정하세요.)
3. 이 폴더(`COVE_인수인계`)를 노트북에 복사하고, **Claude 에서 이 폴더를 엽니다.**
4. Claude 에게 이렇게 말하세요:
   > **"CLAUDE.md 읽고 코브 접속 설정 해줘"**
5. Claude 가 접속용 열쇠를 만들고 **긴 글자 한 줄(공개 열쇠)** 을 보여 줍니다. 그 한 줄을 **담당자에게 보내 주세요.** 담당자가 COVE 에 등록해 주면 준비 끝입니다.
6. 등록됐다고 연락받으면 Claude 에게 **"코브 연결 확인해줘"** 라고 하면 됩니다.

## 5. 매번 작업하는 순서

1. **COVE 전원 켜기** — 켜기 전에 **몸통이 정면을 보고 있는지** 확인해 주세요 (옆을 보고 있으면 방향을 헷갈립니다). 켜지는 데 2~3분 걸려요.
2. 노트북을 **로봇 와이파이**에 연결
3. Claude 에서 이 폴더를 열고: **"코브 연결해줘"**
4. 만들고 싶은 동작을 **말로 설명**합니다 (아래 예시 참고)
5. Claude 가 넣어 주면: **"해봐"** 라고 하면 COVE 가 움직입니다
6. 마음에 들 때까지 **"더 천천히", "고개를 조금 더 들어"** 처럼 고쳐 달라고 하기
7. 끝낼 때: **"오늘 작업 정리해줘"** → Claude 가 만든 동작 목록을 정리하고 저장합니다
8. COVE 전원 끄기 전에 **"처음 자세로 돌려놔"** (home) 하고 끄면 다음에 켤 때 편해요

## 6. Claude 에게 이렇게 말하면 돼요 (예시)

- "고개를 천천히 들고, 왼쪽을 한 번 봤다가, 다시 내려오는 동작 만들어줘. 이름은 hello"
- "몸통을 오른쪽으로 살짝 돌리면서 고개를 갸웃하는 동작"
- "잠 깨는 동작을 더 졸린 느낌으로, 전체적으로 두 배 느리게"
- "물기에서 팔 넣는 시간을 3초에서 5초로 늘려줘"
- "물 때 눈을 감았다가, 놓아줄 때 눈을 깜빡여줘"
- "방금 거 다시 해봐" / "멈춰" / "처음 자세로"
- "지금 있는 동작 목록 보여줘"

말이 애매해도 괜찮아요. Claude 가 "살짝", "천천히" 같은 말을 숫자로 바꿔 넣고, 로봇이 갈 수 없는 범위면 알려 줍니다.

## 7. 안전하게

- **동작을 처음 돌릴 때는 손을 넣지 마세요.** 빈 상태로 한 번 보고, 괜찮으면 그다음에 팔을 넣어 시험하세요.
- 이상하게 움직이면 Claude 에게 **"멈춰"** — 더 급하면 **COVE 전원을 뽑으세요.**
- **"힘 빼줘"** 라고 하면 모터 힘이 풀려 손으로 자세를 잡아 볼 수 있어요. 다시 움직이려면 "힘 줘".
- 무는 힘(세기)은 안전하게 정해 둔 값이라 **더 세게는 못 하게** 되어 있어요. 세기를 바꾸고 싶으면 담당자와 상의해 주세요.
- 오래 돌려서 모터가 뜨거우면 잠시 쉬었다 하세요. Claude 에게 "모터 온도 봐줘" 해도 됩니다.

## 8. 다 끝나면 (돌려줄 때)

- 만든 동작은 **COVE 안에 바로 저장되어 있어서**, 따로 파일을 보낼 필요는 없어요.
- Claude 에게 **"작업 정리해줘"** 라고 해서 만든 동작 목록(이름, 무슨 동작인지, 몇 초)을 받은 뒤, **담당자에게 "다 했어요" 와 함께 그 목록을 보내 주세요.**
- 담당자가 받아서 전시 웹 화면(버튼)과 연결합니다. 동작 이름이 그대로 버튼 이름이 돼요.

## 9. 이럴 땐 이렇게

| 상황 | 해결 |
|---|---|
| Claude 가 "코브에 접속이 안 된다"고 해요 | COVE 전원이 켜졌는지(2~3분 기다리기), 노트북이 `HIDELAB_ROBOWORLD` 에 연결됐는지 확인 |
| 동작을 시켰는데 안 움직여요 | Claude 에게 "코브 프로그램 켜져 있는지 확인해줘" |
| 한쪽 부위가 생각보다 덜 움직여요 | 그 부위가 갈 수 있는 끝에 걸린 거예요. 특히 고개 좌우(4번)는 고개 높이에 따라 많이 제한돼요 |
| 몸통 방향이 이상해요 | 전원 켤 때 몸통이 옆을 보고 있었을 수 있어요. 전원을 끄고 정면으로 돌려놓은 뒤 다시 켜기 |
| 그 밖에 막히면 | 담당자에게 Claude 화면을 캡처해서 보내 주세요 |
