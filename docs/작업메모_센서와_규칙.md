# 작업 메모: 센서와 규칙 (2026-10-30 기준)

Claude와 작업하면서 정한 규칙과 로봇 상태를 모은 메모입니다. 코드에 없는 약속과 로봇 쪽 변경을 여기에 적어 둡니다.

## 센서 호칭

- **거리센서 1번 = 머리**(턱 아래를 보는 VL53L0X). 상태값 `sense.top_mm`, `sense.arm`.
- **거리센서 2번 = 몸통**(앞을 보는 VL53L5CX 4×4). 상태값 `sense.front_mm`, `person`, `dir`, 구역 값은 `booth/robot2/tof`.
- **터치센서**는 로봇을 **앞에서 바라보는 사람 기준 왼쪽부터** 1·2·3번.
  - 1번 = 왼쪽 위 = GPIO17 → **눌러도 신호 없음** (배선 확인 필요, 아래 엔지니어 요청)
  - 2번 = 가운데 조금 아래 = GPIO27 (정상)
  - 3번 = 오른쪽 위 = GPIO22 (정상)
  - 로봇 프로그램 `PIN_TOUCH = {"left": 17, "center": 27, "right": 22}`의 left/right도 앞에서 본 방향과 같다.
- 웹의 센서 표시줄 옆 빨간 글씨: "(모든 센서는 사람 기준 위치입니다)".

## 센서 반응 (웹)

- **2번 몸통**: 앉아 있을 때 손이 다가오면 일어나서 인사 시나리오를 재생한다(끝에 접지 않고 선 채로 끝). 서 있을 때는 이 센서를 보지 않는다.
  - 인식 기준: 그 구역의 평소 거리보다 30% 넘게(20mm 이상) 가까워지고 **센서 값 120mm 이하**(손 약 10cm). 센서 값은 실제보다 1~2cm 크게 나온다. 코드: `robot.js`의 `Z_MAX_MM`.
- **1번 머리(거리센서)**: 손이 들어오면 편안한 눈으로 바꾸고, 손 높이에 맞춰 머리를 숙이면서 기둥도 같이 낮춘다. 거리가 1cm 이내가 되면 거기서 멈추고 더 누르지 않는다. 손이 떨어지면 처음 자세로 돌아온다. 코드: `app.js`의 `ARM_` 상수.
- **머리 터치**: 짧게 톡톡 치면(앉아 있을 때만) 일어난다. 터치센서 1·2·3번을 전부 5초 넘게 만지면 신난 눈 + 몸통 좌우 도리도리 3초.
- **앉기·일어나기 버튼**: 앉기는 감은 눈으로 완전히 접는다(누르면 "앉아 있을 땐 표정만 바꾸기"가 켜진다). 일어나기는 기둥 25° · 머리 -34°로 2.2초에 걸쳐 일어나며 눈을 뜬다.

## 반응이 부딪치지 않게 하는 규칙 (2026-10-30)

로봇 자세를 보내는 곳이 한 번에 하나만 되게 정리했다. 코드: `app.js`의 `motionBusy`, `takeOverPose`, `resetIdleReactions`, `restoreEyes`.

- **버튼이 우선**: 일어나기·앉기·머리 들기·머리 숙이기를 누르면 진행 중이던 센서 반응(손 숙이기, 도리도리, 일어나기 애니메이션, 앉은 뒤 자세 맞추기)을 모두 멈추고, 로봇이 자기 씬을 돌리고 있으면 그 자리에서 세운다.
- **센서 반응은 서로 기다린다**: 일어나는 중이거나 쓰다듬는 중이면 손 숙이기가 기다렸다가, 끝났을 때 손이 아직 있으면 시작한다. 쓰다듬기·톡이 오면 손 숙이기는 잠시 자리를 내주고, 끝나면 숙이기 전 처음 자세를 기억한 채 이어간다.
- **로봇이 스스로 움직일 때는 웹이 반응하지 않는다**: 로봇 자동 모드(`auto`)이거나 로봇이 자기 씬(home 등)을 돌리는 중이면 손 숙이기·쓰다듬기·톡·2번 센서 인사를 시작하지 않는다.
- **눈**: 반응이 끝나면 앉아 있으면 감은 눈, 서 있으면 동작의 눈(로봇은 뜬 눈)으로 돌아온다. 일어나는 동안과 로봇이 따라올 때까지(약 4.7초)는 "앉아 있으면 눈 감기"가 눈을 다시 감기지 못한다. 손 숙이기로 기둥이 낮아진 것은 "앉은 것"으로 보지 않는다.
- **2번 센서 인사**: 다른 반응이 진행 중이거나, 일어난 직후이거나, 1번 거리센서(머리)에 손이 있거나 막 떼었을 때(3초)는 반응하지 않는다. 손이 머리 아래로 들어오면서 몸통 앞도 지나가기 때문이다.

## 눈 표정 규칙

- 기분 좋을 때는 **신난 눈**으로 통일(표정 모음만 예외).
- 슬픈 장면은 **눈물 눈**.
- 앉아 있을 때는 **감은 눈**.
- 위 보는 눈(뜬 눈을 한 줄 올린 모양)은 만들어 뒀지만 지금은 쓰지 않는다. 터치 3번→2번 / 1번→2번 갸우뚱 반응(`SIDE_LOOK_ON`)을 꺼 둬서 평소에는 뜬 눈을 쓴다.

## 엔지니어에게 보낼 내용 (터치센서 1번)

> **터치센서 1번(앞에서 바라볼 때 머리 왼쪽 위) 신호가 안 들어옵니다. 배선 확인 부탁드립니다.**
>
> - 센서 배치(앞에서 바라볼 때): 1번 = 왼쪽 위, 2번 = 가운데(조금 아래), 3번 = 오른쪽 위.
> - 로봇 프로그램의 `PIN_TOUCH = {"left": 17, "center": 27, "right": 22}` 중 **GPIO17(left)** 이 1번인데, 눌러도 한 번도 HIGH가 되지 않습니다. 2번(GPIO27), 3번(GPIO22)은 정상입니다.
> - 확인한 내용: `pinctrl get 17`로 읽으면 항상 `lo`이고, 풀업으로 바꿔 읽으면 `hi`로 올라갑니다. 즉 **센서 출력이 GPIO17에 연결되지 않았거나 신호선이 떠 있는 상태**입니다. (GPIO27, 22는 풀업으로 읽어도 `lo`라서 센서가 신호를 잡고 있습니다.)
> - 부탁드릴 것: 1번 터치 센서(TTP223)의 전원(VCC, GND)과 출력(OUT) 선이 GPIO17에 제대로 연결돼 있는지, 센서 자체가 정상인지 확인 부탁드립니다. 고친 뒤 눌러서 GPIO17이 HIGH가 되는지 봐 주세요.
> - 참고로 웹에서 센서별로 구분해 쓰려고 로봇 프로그램에 아래를 추가했습니다(백업: `backups/cove_robot_before_touch_each_1030_1145.py`). `snapshot()`의 `sense`에 `touch_each: [왼쪽, 가운데, 오른쪽]`과 `touch_recent: [..]`(최근 1.6초 안에 닿았는지)를 넣었고, `_touch_loop`에서 센서별 값을 저장합니다. 거리센서(ToF)는 프로그램만 다시 시작하면 "ID register" 오류로 꺼져서 전원을 껐다 켜야 살아났습니다. 이 부분(재시작 시 ToF 초기화)도 확인해 주시면 좋겠습니다.
