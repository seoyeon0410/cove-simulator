## 3. 눈 표정 — JSON 형식 제안

로봇은 씬 안에서 `{"eyes": "이름"}` 단계로 표정을 바꿉니다. 아래 형식으로 주시면 그대로 넣겠습니다.

```json
{
  "version": 1,
  "rows": 4,
  "cols": 8,
  "eyes": {
    "뜬 눈":   { "left": ["00111100", "01111110", "01111110", "00111100"],
                "right": ["00111100", "01111110", "01111110", "00111100"] },
    "반짝 눈": { "frames": [
                  { "left": ["..."], "right": ["..."], "ms": 120 },
                  { "left": ["..."], "right": ["..."], "ms": 120 } ],
                "loop": true }
  }
}
```

- 각 눈은 **위에서부터 4줄**, 한 줄은 문자 8개(`1` = 켜짐), **맨 왼쪽 문자 = 로봇 기준 왼쪽 칸**.
- `left` = 로봇의 왼쪽 눈(I²C 0x70), `right` = 오른쪽 눈(0x71). 두 눈이 같으면 `"right"` 생략 가능.
- 애니메이션은 `frames` + 프레임별 `ms`, 반복이면 `"loop": true`.
- 이름은 웹 표정 이름(한글) 그대로 써도 됩니다. 씬에서는 `{"eyes": "웃는 눈"}` 처럼 씁니다.
- 깜빡임: 지금 로봇의 `idle`(뜬 눈)은 자체 깜빡임이 있습니다. 웹 규칙(3.8초 주기, 5프레임 60ms)으로 맞추길 원하시면 "뜬 눈"의 깜빡임 프레임도 같이 주세요.
- 웹 모션 CSV 와 같이 재생하려면 표정 시간표(`[{ "t": 0, "expr": "졸린 눈" }, ...]`)를 씬마다 주시면, 로봇 씬에 시간 맞춰 `eyes` 단계를 넣겠습니다.

## 4. 실시간 조그 `pose`

```json
{"cmd": "pose", "deg": {"neck": 10, "head": -12, "tilt": 0, "body": 0}}
```

- 토픽 `booth/robot2/cmd` (웹소켓 `ws://192.168.1.232:9001`). 일부 관절만 보내도 됨 (보낸 관절만 움직임).
- 각도 → 틱 변환 (로봇 안에서):
  - neck: `ID2 = 3201 − 11.378 × neck`
  - head: `ID3 = 3074 + 11.378 × head` (목 기준 상대각으로 처리)
  - tilt: `ID4 = 2021 + 11.378 × tilt` (웹 가정 방향 — `check_tilt` 결과가 반대면 로봇 쪽 부호를 바꿈, 웹은 그대로)
  - body: `ID1 = 1600 + 29.6 × body`
- 범위 밖·갸웃 연동 한계는 로봇이 자름 (답변서와 같은 한계).
- **0.1초 간격(10Hz)** 기준. 프레임마다 0.15초에 걸쳐 움직여 다음 프레임과 겹치게 → 부드럽게 이어짐.
- 씬 재생 중에 pose 가 오면 씬을 멈추고 조그로 넘어감. 센서 반응 시나리오는 조그 중에는 쉼.
- **2초 동안 pose 가 안 오면 조그 끝** — 그 자세를 유지 (목을 든 채로 끝나면 처지지 않게 힘 유지). 제자리로는 `home` 씬.
- 안전상, 사람 팔이 머리 밑에 있을 수 있는 "휴식" 시나리오 도중에는 pose 를 무시합니다.
- ※ 로봇 프로그램 재시작 후 사용 가능 (오늘 재시작 예정).
