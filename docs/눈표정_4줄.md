# 눈 표정 4줄 비트맵 미리보기

`cove_eyes.json` 의 내용을 사람이 보기 쉽게 그린 것입니다. 로봇 기준 좌우이고, 위 4줄 × 8칸입니다. (`█` = 켜짐)

두 눈 사이를 최대한 벌리기 위해 왼쪽 눈은 왼쪽으로, 오른쪽 눈은 오른쪽으로 가장자리까지 밀어 두었습니다.

> 좌우 비대칭 표정(윙크, 슬픈 눈, 신난 눈, 눈물 눈, 편안한 눈)은 로봇에 올린 뒤 좌우가 맞는지 한 번 봐 주세요. 반대로 보이면 알려 주세요. 바로 뒤집어 드리겠습니다.

## 씬별 표정 시간표
`cove_eyes.json` 의 `scenes` 에 있습니다. 씬 이름은 `web_*` 와 같고, `t` 는 모션 CSV와 같은 시간(초)입니다. 시선이 옆으로 가는 곳에는 `gx`(칸, 웹 기준 오른쪽 +)가 있습니다. 세로 시선(gy)은 4줄에서는 쓰지 않습니다.

- `web_rest`: 0s 졸린 눈, 1.2s 뜬 눈, 3s 반짝 눈, 4.2s 웃는 눈, 6s 뜬 눈 …
- `web_tickle`: 0s 졸린 눈, 1.2s 뜬 눈, 4s 뜬 눈, 6s 반짝 눈, 8s 신난 눈 …
- `web_snack`: 0s 졸린 눈, 1.2s 뜬 눈, 3s 뜬 눈, 6s 반짝 눈, 9s 놀란 눈 …
- `web_greet`: 0s 졸린 눈, 1.5s 뜬 눈, 3s 반짝 눈, 4.5s 초롱 눈, 6s 웃는 눈 …
- `web_praise`: 0s 졸린 눈, 1.5s 뜬 눈, 3s 편안한 눈, 5s 감은 눈, 7s 웃는 눈 …
- `web_surprise`: 0s 감은 눈, 2s 졸린 눈, 4s 놀란 눈, 5.5s 초롱 눈, 7s 뜬 눈 …
- `web_look`: 0s 졸린 눈, 1.5s 뜬 눈, 3s 뜬 눈, 4.5s 반짝 눈, 6s 뜬 눈 …
- `web_bye`: 0s 뜬 눈, 1.5s 점 눈, 3s 슬픈 눈, 5s 눈물 눈, 7s 초롱 눈 …
- `web_expressions`: 0s 뜬 눈, 1s 감은 눈, 2.4s 웃는 눈, 4.8s 반짝 눈, 7.2s 초롱 눈 …
