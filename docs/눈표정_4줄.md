# 눈 표정 4줄 비트맵 미리보기

정면에서 볼 때 왼쪽 눈 / 오른쪽 눈이고, 위 4줄 × 8칸입니다. (`█` = 켜짐) 그림은 **눈에 보이길 원하는 모양**입니다.

실물 LED가 한 칸 오른쪽으로 밀려 켜지고 맨 오른쪽 칸이 맨 왼쪽으로 넘어가기 때문에, `cove_eyes.json` 의 글자는 이 그림보다 **왼쪽으로 한 칸 돌려서** 적혀 있습니다. 두 눈은 바깥 가장자리까지 밀어 간격을 최대로 벌렸습니다.

> 좌우 비대칭 표정(윙크, 슬픈 눈, 신난 눈, 눈물 눈, 편안한 눈)은 로봇에 올린 뒤 좌우가 맞는지 한 번 봐 주세요.

## 씬별 표정 시간표
`cove_eyes.json` 의 `scenes` 에 있습니다. 씬 이름은 `web_*` 와 같고, `t` 는 모션 CSV와 같은 시간(초)입니다.

- `web_rest`: 0s 졸린 눈, 1.2s 뜬 눈, 3s 반짝 눈, 4.2s 웃는 눈, 6s 뜬 눈 …
- `web_tickle`: 0s 졸린 눈, 1.2s 뜬 눈, 4s 뜬 눈, 6s 반짝 눈, 8s 신난 눈 …
- `web_snack`: 0s 졸린 눈, 1.2s 뜬 눈, 3s 뜬 눈, 6s 반짝 눈, 9s 놀란 눈 …
- `web_greet`: 0s 졸린 눈, 1.5s 뜬 눈, 3s 반짝 눈, 4.5s 반짝 눈, 6s 웃는 눈 …
- `web_praise`: 0s 졸린 눈, 1.5s 뜬 눈, 3s 편안한 눈, 5s 감은 눈, 7s 웃는 눈 …
- `web_surprise`: 0s 감은 눈, 2s 졸린 눈, 4s 놀란 눈, 5.5s 반짝 눈, 7s 뜬 눈 …
- `web_look`: 0s 졸린 눈, 1.5s 뜬 눈, 3s 뜬 눈, 4.5s 반짝 눈, 6s 뜬 눈 …
- `web_bye`: 0s 뜬 눈, 1.5s 점 눈, 3s 슬픈 눈, 5s 눈물 눈, 7s 반짝 눈 …
- `web_expressions`: 0s 뜬 눈, 2.4s 웃는 눈, 4.8s 반짝 눈, 7.2s 별 눈, 9.6s 하트 눈 …
