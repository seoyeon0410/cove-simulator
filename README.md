# 코브 애니메이터

GLB 리그(본)를 조작하고 키프레임으로 애니메이션을 만드는 웹 도구. three.js 기반, 빌드 없음.

## 실행
```bash
python3 server.py 5173
```
브라우저에서 http://localhost:5173 을 연다. 다른 GLB는 끌어다 놓거나 [GLB 열기].

## 기능
- 본 선택/이동/회전, `IK_타겟` 평면 IK, 자동 키
- 타임라인 키프레임 편집(이동·복사·보간), 클립 관리, 프리셋 클립
- GLB(원본 리그 유지 + 애니메이션 교체) / PNG / MP4 내보내기
- 시나리오 8개 + 표정 모음, 눈 표정(8×8 도트) 고르기·끌어서 만들기, 관절 조작 슬라이더(로봇 최소·최대 표시)
- 로봇 연결(MQTT): 씬 실행·정지·토크·눈 바꾸기, 웹 재생을 로봇이 실시간으로 따라 하기, 로봇용 모션(CSV)·눈(JSON) 내보내기
