코브 애니메이터 사용법
====================

1. 켜기
   - 맥:      "시작하기.command" 를 더블클릭
              (처음에 "확인되지 않은 개발자" 경고가 뜨면: 파일을 오른쪽 클릭 → 열기 → 열기)
   - 윈도우:  "시작하기.bat" 를 더블클릭
   - 브라우저(크롬 권장)에 http://localhost:5173/ 이 열려요.
   - 컴퓨터에 Python 3 가 있어야 해요. 없으면 https://www.python.org/downloads/ 에서 설치
     (윈도우는 설치할 때 "Add python.exe to PATH" 체크).
   - 끄려면 검은 창(터미널)을 닫으세요.

2. 웹에서 모션 보기 (로봇 없이도 돼요)
   - 왼쪽 "동작 목록"에서 시나리오를 고르고 아래 ▶ 를 누르면 3D 로봇이 움직여요.
   - 휴식·간지럽히기는 중간에 멈춰서 초록 버튼(반응하기, 숙이기, 간지럽히기 등)을 눌러야 이어져요.
   - "표정 고르기" 줄을 마우스로 쓸면 눈 표정이 바뀌어요.

3. 실제 로봇 제어하기
   - 컴퓨터가 로봇과 같은 네트워크(와이파이)에 있어야 해요. 로봇 서버(MQTT)는 ws://192.168.1.232:9001 이에요.
   - 화면 위쪽 "로봇 연결" → 주소가 맞는지 보고 [연결]. 로봇 상태가 나오면 연결된 거예요.
   - 움직이려면 "로봇 주변을 확인했어요"를 체크해야 해요. 로봇 주변에 사람·물건이 없는지 먼저 보세요.
   - 로봇 동기를 켠 채로 웹에서 ▶ 를 누르면 로봇이 웹 모션을 따라 해요.
   - 로봇 머리의 터치센서와 1번 거리센서(머리, 턱 아래)에 반응해 멈춤 버튼이 자동으로 넘어가요.
   - 2번 거리센서(몸통 앞)에 손을 10cm 안으로 가까이 대면 앉아 있던 로봇이 일어나요(첫 장면만 재생하고 선 채로 멈춰요). 서 있는 동안 더 가까이 올수록 기둥도 더 올라가요(동기가 켜져 있을 때). 패널 스위치로 끌 수 있어요.
   - 센서 이름: 1번 = 머리에 있는 거리센서, 2번 = 몸통에 있는 거리센서.
   - 재생 안 할 때: 머리를 톡 치면 고개를 올리고, 쓰다듬으면 신난 눈으로 기뻐하며 몸을 흔들어요(동기가 켜져 있을 때).

4. 위험할 때
   - "■ 정지" 또는 "■ 전체 정지" 버튼을 누르세요. 로봇은 와이파이가 끊기면 그 자리에서 멈춰요.
   - 로봇에 걸리는 소리가 나거나 이상하게 움직이면 바로 정지하고 전원을 확인하세요.

5. 더 자세한 내용
   - docs/인수인계_코브애니메이터.md (로봇 접속 정보, 파일 올리는 절차, 눈 표정 특성, 안전 규칙)
   - 모션을 로봇에 올리는 파일은 docs/cove_web_motions.zip 과 docs/cove_eyes.json 이에요.
     (덮어쓰기 전에는 로봇의 backups 폴더에 백업하세요)
